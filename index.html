Spatial Modeling of Vegetation Dynamics & Future Climate Scenarios

Google Earth Engine • Python • Predictive Modeling

Executive Project Abstract

An advanced spatial analytics pipeline engineered to model ecosystem dynamics and mitigate environmental risk within Nyanga National Park. This research executed a precise 21-year temporal baseline analysis (2003–2023) to evaluate historical vegetation stress and model near-future climate scenarios.

Technically, the project processed multi-sensor satellite imagery across Google Earth Engine. By replacing standard categorical trend classes with a highly sensitive stability index, and deploying Random Forest machine learning classification, the model achieved superior predictive accuracy.

Commercial Value: By providing audit-ready spatial intelligence, it allows corporate stakeholders to eliminate costly manual field surveys and optimize capital resource allocation against climate-induced degradation.

Asset-Centric Environmental Risk Engine

Live API Feed • Spatial Intersection Logic (Leaflet + Turf.js)

Executive Project Abstract

A dynamic, full-stack Web GIS dashboard designed to solve a critical operational vulnerability: the financial loss caused by localized climate anomalies impacting active commercial operations.

This engine mathematically cross-references live meteorological API data against specific infrastructure vector layers (e.g., operational concessions, haul roads). Utilizing dynamic spatial buffering, the system highlights precisely which physical assets fall within high-risk intersection zones.
